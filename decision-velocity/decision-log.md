# Decision Log

> A running record of the decisions that matter. It takes two minutes per entry and it answers questions nothing else can: where do decisions get stuck, which ones do we keep remaking, and who is actually deciding.

## What to log

Not every decision. Log a decision if any of these are true:

- It is a one-way door (hard to reverse)
- It needed more than one person to agree
- It changed the roadmap
- Someone will ask "why did we do this?" in six months

## The log

| # | Decision | Type | Owner | Prepared by | Raised | Decided | Days | Door | Revisited? | Link |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | *Sunset legacy recommendations service before Q3* | Roadmap | *Name* | Agent-assisted | 2026-03-02 | 2026-03-09 | 7 | One-way | No | *memo* |
| 2 | | | | | | | | | | |

**Column notes**

- **Type:** use a small, fixed set so you can compare over time. I start with: *Roadmap, Pricing, Hiring, Build vs. buy, Launch, Stop/sunset, Policy.*
- **Raised:** the day someone first asked for a decision, not the day a meeting was scheduled.
- **Prepared by:** *Person* or *Agent-assisted*. Agent-assisted means an agent prepared the memo, analysis or options, and a person decided. Agents never decide. This column is how you find out whether agents actually make decisions faster or better.
- **Days:** decided minus raised. This is the number that matters.
- **Revisited?:** did we make this decision again later without new information? If yes, note when. Remade decisions are the most expensive kind.

## Reading it

Once a month, look at four things:

1. **Median days by type.** Which kinds of decisions are slowest here?
2. **Revisited decisions.** Why did not the first one stick? Usually: no owner, no written record, or the people who disagreed were not heard.
3. **Who decides.** If one or two names own most of the log, the org is routing too much to the top.
4. **Agent-assisted versus not.** Compare days and revisits for the two groups. If agent-assisted decisions are not faster or more durable after a quarter, the agents are producing work, not value.

For turning this into a metric you can report, see [measuring.md](measuring.md).
