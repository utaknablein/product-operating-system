# Worked examples

Every template in this repo, filled in for one fictional company so you can see how the pieces connect.

**Lumen** is an invented subscription audio-learning app with about 1.2 million paying subscribers, a product team of 40, and a problem most product organizations will recognize: two recommendation systems running side by side, each with its own owner, metric and roadmap line. Nothing here describes a real company, person or dataset.

One decision runs through all four examples:

```
decision memo ──> product brief ──> decision log
 "Retire the legacy    "Unified Home     entry #4, 6 days,
  recommender?"         Feed"             agent-assisted
        ^
        │ drafted by
  agent role card: Decision memo agent
```

| Example | Template it fills in | Read it to see |
|---|---|---|
| [Decision memo](decision-memo-example.md) | [`templates/decision-memo.md`](../templates/decision-memo.md) | What a one-page memo with real options, a real "do nothing" row and a visible disagreement looks like |
| [Product brief](product-brief-example.md) | [`templates/product-brief.md`](../templates/product-brief.md) | A bet statement, one primary metric with a guardrail, and an "out" list that will protect the team in week three |
| [Agent role card](agent-role-card-example.md) | [`templates/agent-role-card.md`](../templates/agent-role-card.md) | Decision rights for an agent, with the "never" column written first |
| [Decision log](decision-log-example.md) | [`decision-velocity/decision-log.md`](../decision-velocity/decision-log.md) | A quarter of entries, the four monthly readings, and what the numbers say about Lumen |

Start with the memo. If you only have thirty minutes, use the [quick start](../QUICKSTART.md) instead and write your own.
